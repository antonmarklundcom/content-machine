  instead of the node/git "open page and wait" fallback, so the installer never blocks on them.
- Commands and pages from unmerged phases are named with "arrives with S1x/O1x"; S20 should
  drop those markers once lane 2 is merged.
- `setup.ps1` still offers only the poll + weekly schedules; media:scan/prune are schtasks lines in docs.
