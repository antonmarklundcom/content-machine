# O8 — Titles + script generation

## Built

- `src/lib/scripts/contract.ts`: `ScriptBodyV1` (version, language, topic, chosenTitle,
  targetMinutes, 3 titleOptions, 3 thumbnailConcepts, hook, sections, cta, sources) +
  `validateScriptBody()` — every error as `<path> <what is wrong>`, unknown fields refused at
  every level, section `sourceIds` must name a source. 6 unit tests.
- `content/style/{en,es-PY,jopara}.md` (≤ 53 lines each): on-camera rhythm, voseo +
  Paraguayan vocabulary + softeners, jopara's safe Guaraní word list and when not to use it.
- `ai.ts`: `generateTitles` (10 + angle, ungrounded, LOW thinking) and `generateScript`
  (Search-grounded, structured output, sources with URLs, verify flag), both in `withSpendCap`;
  `assembleScriptBody` repairs URL-less sources (dropped + "UNSOURCED — verify or cut" talking
  point) and dangling source ids. Fake: `titles` + `script` payloads/usage.
- `scripts/brief.ts` (lessons for prompts, competitor analyses → structure references),
  `scripts/language.ts` (default language, style guide loader, `needsVerification`),
  `scripts/export.ts` (teleprompter md, shot list md + fenced JSON), `scripts/owner-gate.ts`.
- Routes: `POST /api/scripts/titles`, `POST /api/scripts` (201, draft saved via the bridge),
  `GET /api/scripts/[id]/export?format=md|json|shots` (`&as=json`, `&download=1`).
- 8 integration tests (`scripts-engine.test.ts`), 8 more unit tests (export, language, assembly).

## Decisions

- **Competitor analyses travel as structure only** — hook technique, beat order, gaps. Their
  summary/takeaways never reach the prompt (asserted), so there is no wording to copy.
- **Verify flag = model's OR a regex floor** (law, residency, tax, fees, prices, deadlines,
  currency, "N days"): over-flagging costs a glance, under-flagging costs a wrong fact on camera.
- **Repair, don't reject, the two cheap model mistakes** — the call is already billed.
- **`format=shots` is Markdown with the JSON list fenced at the end** (§1.34 "Markdown + JSON"
  in one paste); `&as=json` for S12's slash command. Files: `media/<id>/<nn>-<slug>.{png,mp4}`,
  thumbnails `media/<id>/thumb-<n>-<slug>.png`.
- **Export is sign-in only, not owner-gated** — it spends nothing.
- **Script writes are not streamed** (unlike `/api/generate`): local-first, no function timeout.

## Known issues

- **No live run.** No `GEMINI_API_KEY`/`DATABASE_URL` in this environment; §7 item 9 added.
  The reservation constants (`SCRIPT_*`, `TITLES_*`) are unmeasured estimates.
- Swedish (`sv`) brands fall back to English — there is no Swedish style guide (§1.33 lists three).
- Source URLs are the model's, not the grounding chunks' redirect URIs; a plausible-but-wrong URL
  passes the contract. The verify flag and the teleprompter's ⚠ markers are the mitigation.
- Style guides are read from `process.cwd()/content/style` — fine locally; a Vercel deploy would
  need them in the output file tracing.
