## Decisions

- **`ScriptBodyValidator = (body) => {ok:true} | {ok:false, errors}`** — O8's contract module
  adapts to this; the bridge throws `InvalidScriptError` (with `errors`) before any write.
- **The outlier SQL is held to the pure function** by an integration test over 50+ videos, so
  the two definitions cannot drift. Baseline = channel's last 30 with a view count, overall
  (not just the window), newest `published_at` first, nulls last, id desc on ties.
- **The fallback's `store` callback runs inside `withSpendCap`**; `insertAnalysis` is the one
  `recordSpend`, so the call bills once. Also refuses a video that has a transcript.
- **Raw-SQL timestamps are read as UTC** (drizzle writes UTC; Anton's PC is not in UTC).
