# S18 — Facts import + hooks library

## Built

- `src/lib/facts/import.ts`: `parseFactsSource` (the `export const facts = {…}` literal, or a JSON
  file), `factRowsFrom` (one row per key × locale; hedged text when unverified, display when
  verified; topic = key's first segment; source = `sourced.url` or first `sources` URL;
  `lastCheckedAt` from `verifiedOn`/`sourced.checkedOn`), `importFacts`, `fetchFactsSource`.
- `npm run facts:import -- --family <id> --source <path|url> [--dry-run]` (`scripts/facts-import.ts`).
- `/facts`: family chips (`?family=`, `&lang=`), family facts grouped by topic with an
  "Unverified" badge, language and key; owner-only "Import facts" form (file upload or URL).
- `/hooks`: `hook` / `cta` / `caption_pattern` lessons; kind, family and brand filters (a brand
  shows its own + its family's; a family shows shared + every member's), quick add, copy, delete.
- Tests: `tests/integration/facts-import.test.ts` (6) against the fixture copy of the facts file.

## Decisions

- A locale is imported only where the stored text exists in it: a plain-string hedge is `en` only,
  never English filed under `es`/`pt`/`sv` (O11's generation already falls back to base/`en`).
- Locales are kept as the source writes them (`pt`, not `pt-BR`); O11 matches the base language.
- Upsert writes nothing for an unchanged row (re-run = no-op); `updatedAt` moves only on a new
  claim or source, as in `bridge/facts.ts`. Nothing is deleted when a key leaves the source.
- No transaction (neon-http has none); every write is idempotent on re-run.
- Hook writes are any signed-in user (like `/lessons`); facts import is owner-only (like facts).
