# S12 — Script studio UI + Higgsfield hand-off

## Built

- `/studio`: scripts filtered by brand and status (query-string pills), newest edit first.
- `/studio/new`: brief form (brand, language, length, topic, analysed reference videos, brand + shared
  lessons) → "Suggest titles" (`POST /api/scripts/titles`) → pick/type → "Write script"
  (`POST /api/scripts`) → `/studio/<id>`. `?brand=` and repeated `?ref=<videos.id>` preselect;
  a ref with no ok analysis is named with a link to analyse it.
- `/studio/[id]`: editor for basics, title options, thumbnails, hook, sections (reorder/add/remove,
  source checkboxes), b-roll shots with Higgsfield prompts, CTA, sources; status buttons; copy/download
  of the md/json/shots exports. "Verify before recording" badge on sections citing flagged sources.
- `/studio/[id]/teleprompter`: spoken lines only, white on black, rAF auto-scroll, speed + size
  sliders, Space pause, ↑/↓ speed, +/− size, F full screen, Home top; badge on flagged sections.
- `studio.actions.ts`: `saveScript` (validates with `validateScriptBody`, returns errors as data, saves
  via `updateScriptBody`, title/language follow the body) and `setStudioScriptStatus`.
- `.claude/commands/higgsfield-shots.md` + `docs/HIGGSFIELD.md`; en + sv copy in `dict/scripts.ts`.
- Tests: `tests/integration/studio-ui.test.ts` (create → edit → status → export; invalid body never
  saved; auth/unknown status), `src/app/studio/model.test.ts` (helpers + teleprompter render).

## Decisions

- **Validate twice, save never on failure**: the editor runs the contract validator for instant inline
  errors (each shown under the part its path names), the action runs it again; nothing reaches the bridge.
- **`normalizeBody` before validation**: text areas are one line per row; blanks dropped, lines trimmed,
  empty video prompt → `null` (a still).
- **Editing is signed-in, not owner-only** (spends nothing, same as ideas); generating stays owner-gated in O8.
- Teleprompter is its own route reading the *saved* script, so it can be opened on a second screen.
- Studio reuses the YouTube section's `Header` via its own layout; no nav edit (S9 adds the link).
