# S15 — Posts, calendar, post pack

Branch `phase/s15-posts-calendar` off main at `8744d7b` (O11 merged).

## Built

- `/posts`: list filtered by account, status and a from/to date range (the post's date), paged.
- `/posts/new`: account + approved idea or topic + format → `createPostAction` (owner-only, spends).
- `/posts/[id]`: editor for hook, caption, CTA, hashtags, engagement mechanic, first comment, alt
  text, slides/shots/story frames (add/remove), sources and notes; one Save validated by O11's
  `updatePost`; files attached from the brand's library, reordered (↑/↓), role set, detached;
  status buttons greyed by O11's `checkTransition`; date + "Save and schedule"; "Export brief"
  (Markdown + JSON links); "Adapt to family" and the family versions.
- `/posts/[id]/pack`: phone-first pack — big "Copy caption", first comment / alt text, files in
  order with download links, permalink + "Mark posted".
- `/calendar`: week and month views per account or family; HTML5 drag to another day keeps the
  local time of day (`schedulePostAction`); the editor's date field is the fallback.
- `src/lib/posts.actions.ts`: create, adapt, save, set status, schedule, mark posted, and the
  `post_assets` writers (attach, reorder, set role, detach).
- `src/app/calendar/model.ts` (+ unit test), `src/app/posts/model.ts`, `dict/posts.ts` en + sv.
- `tests/integration/posts-ui.test.ts`: create, attach/reorder, schedule, mark posted (5 tests).

## Decisions

- `post_assets` has no writer in O11's modules, so the actions write it (§4.7 allows actions).
  Reorder rewrites 1..n in one transaction (the PK is `(post_id, position)`).
- Every status move goes through O11's `setStatus`/`updatePost`; `publishing`/`failed` get no
  buttons (O13's). "Mark posted" is `updatePost({ permalink, status: "published" })`.
- Only files of the post's brand or the unsorted inbox can be attached; the picker lists both.
- Calendar days are placed in the viewer's time zone after mount; the server fetches ±14 h.
- Clearing the date of a scheduled post is refused; move it back to ready first.

## Known issues

- Media thumbnails and downloads are owner-only (O10's route), so an employee sees blank tiles.
- No "regenerate one section" button yet; the route exists (`/api/posts/[id]/regenerate`).
- Drag-to-reschedule is mouse-only (HTML5 DnD); on a phone use the editor's date field.
- The picker shows the first page (60) of each list; older files need the media library first.
- The idea board has no "Write post" link to `/posts/new?idea=` yet (S20 mounts).
