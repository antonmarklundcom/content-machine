# S21 — IG competitors + weekly report

Branch `phase/s21-ig-competitors` off main at `18f0ff6`.

## Built

- `src/lib/meta/discovery.ts`: Business Discovery lookup through Anton's own linked IG account
  (`business_discovery.username(<handle>){…media.limit(25){…}}`), handle normalising (`@`, URLs),
  add/remove competitors, sync upserting `competitor_posts` by media id (`REELS` stored as `REEL`,
  `view_count` → `views`), followers + `external_id` on the competitor row.
- Ranking: each post's likes + comments against the median of that competitor's stored posts (§1.30).
- Weekly report per own IG account: own posts published in 7 days with newest metrics and engagement
  rate (§1.51), followers start/end + reach from `account_metrics`, the brand's best competitor posts,
  three next-post suggestions (one per competitor first, then a follow-up to our own best post).
- `/research/instagram` (brand chips, tracked accounts, add/remove/look up — owner only, best posts of
  30 days) and `/research/instagram/report?account=<id>`; components `IgCompetitorTable`, `IgCompetitorPosts`.
- `scripts/ig-competitors.ts`: sync + prints each account's weekly report; exit 1 on a failed lookup.
- `tests/integration/ig-competitors.test.ts` (9) on inline recorded shapes; no test reaches Meta.

## Decisions

- Non-Business/Creator (Graph code 110 / subcode 2207013) → `last_error` = "Not available…", not a failure.
- The viewer is a linked IG account of the same brand when there is one, else any linked IG account.
- Suggestions are built from the ranked posts, no model call (`src/lib/ai.ts` is not in Owns).
- No `package.json` script (not in Owns): run `npx tsx --conditions=react-server scripts/ig-competitors.ts`.
- New `dict/igCompetitors.ts` + its import and two spreads in `dictionary.ts` (§4.9).
