# O12 — Meta connect + insights

Branch `claude/zen-planck-mzickk` (harness-pinned) off main at `4a7f3d9`.

## Built

- `src/lib/crypto.ts`: AES-256-GCM (`v1:iv:tag:ct`) with `ENCRYPTION_KEY`; a missing or bad key disables Meta with a message.
- `src/lib/meta/`: Graph client (injectable fetch, token redaction), Facebook Login for Business
  (`config_id` if `META_LOGIN_CONFIG_ID`, else `scope`), code → long-lived token, Page/IG discovery,
  linking (IG by handle, Pages by hand), expiry handling + banner, sync, setup checklist.
- Routes `/api/meta/connect` (state cookie), `/api/meta/callback`, `/api/meta/sync` (owner only).
- Settings → Meta: six guided steps with done / to-do / "checked after step 5", Meta links, the
  redirect URIs (localhost:3000 + current origin), key form writing `.env`, Connect, mapping, Sync now.
- `npm run meta:sync`: IG per-media insights per type (reel / carousel / image / video / story) and FB
  Page posts → `post_metrics` (append-only, `raw` kept); yesterday's `account_metrics` upserted.
  Matches by `external_media_id`, else permalink (then records the media id).
- `src/lib/posts/what-worked.ts` → `PostTarget.whatWorked` → a "WHAT WORKED" block in `draftPost`.
- Tests: `tests/integration/meta-insights.test.ts` (11) on fixtures in `tests/integration/fixtures/meta/`; `src/lib/meta/setup.test.ts`.

## Decisions

- One `integrations` row per Meta user (`account_ref` = user id); Page tokens fetched per sync, never stored.
- Publishing scopes are requested now so O13 needs no reconnect.
- Graph v22+ `views` fills `plays` (reel/video) or `impressions` (others); an unsupported metric retries with a basic set.
- Outside Owns, at Anton's request or required by §5.O12: `.env.example` (META\_\*, ENCRYPTION_KEY),
  `package.json` (`meta:sync`), `src/lib/posts/engine.ts` (one `whatWorked` call), `dict/meta.ts` + its dictionary lines.
- Default Graph version `v23.0` (`META_GRAPH_VERSION` overrides).
