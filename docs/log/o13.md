- Tests: `src/lib/publish/plan.test.ts`; `tests/integration/publish.test.ts` (13) on `fixtures/meta/publish/`.

## Decisions

- An error on the call that makes a post public (5xx / unreachable) is never auto-retried: it may be live. The IG
  container is kept, so "Publish now" re-publishes that same container instead of creating a second post.
- Only temporary errors before that point (rate limit, 5xx, unreachable) are retried; they are stored with the
  `Temporary: ` prefix, which is how the due run recognises them.
- A published post whose permalink read or first comment fails stays `published`, with the note in `publish_error`.
- Outside Owns, required by §5.O13: `package.json` (`publish:due`), one mount + import in `src/app/posts/[id]/page.tsx`,
  `src/lib/i18n/dict/publishNow.ts` + its dictionary lines.
