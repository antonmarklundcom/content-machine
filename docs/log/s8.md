## Decisions

- **`start.bat` tests `.next\BUILD_ID`, not `.next`**: `npm run dev` creates `.next`
  without a production build, and `next start` would then fail. So it still
  does not rebuild after `git pull` — LOCAL-SETUP's update step ends with `npm run build`.
- The browser opens after a 5 s delay in a side `cmd`, so it does not hit a server still starting.
- `DB_DRIVER=pg` is presented as required locally (§1.27), not optional.
