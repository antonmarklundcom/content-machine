## Decisions

- No `output: "standalone"`: Hostinger runs `npm start` = `next start`, which refuses a standalone build.
- `src/db/driver.ts` unchanged: IPv4 is already forced in `src/db/index.ts` (`DB_FORCE_IPV4=1` → `ipv4first`), which is
  where the pg pool is created; nothing more is needed.
- `package.json` unchanged: no new script is needed for deploying.
- The Drive driver has its own `DriveDriver` type (`name: "drive"`, `link()` instead of `publicUrl`): the shared
  `StorageDriver.name` union is outside Owns, and a Drive view link must never reach a publisher as a public URL.
- `MEDIA_ROOT` online: recommend leaving it unset so drive-dependent pages honestly say "not connected".
