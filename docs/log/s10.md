# S10 — Competitor research

## Built

- `/research` (+ layout with the token `Header`): brand chips and 30/90/365-day window in the
  query string (`?brand=<id>&days=<n>`), so every view is a shareable link.
- Channels: paste a channel URL (URL or `@handle`) → tracked as a source and linked; role
  toggle competitor ⇄ inspiration; remove (unlinks only, source and videos stay).
- Outlier board: thumbnail, title, channel, views, date, score, digest summary; "Analyse"
  (existing `analyzeVideoAction`, owner only), "Open digest", "Use as reference" →
  `/studio/new?brand=<id>&ref=<videoId>`.
- Title patterns panel: top 10 outlier titles with scores, one "Copy titles" button.
- `research.actions.ts`: `addCompetitorChannel`, `setCompetitorRole`, `removeCompetitor`.
- `dict/research.ts` en + sv. `tests/integration/research-ui.test.ts`: link by URL / handle
  (upsert, no duplicates), role toggle, unlink, refusals before any YouTube call.

## Decisions

- **Add goes through the source action's own path** (`parseYouTubeUrl` → `resolve` →
  `upsertChannelSource`), not `addSource`, because that action does not return the row id.
- **All three actions are free, so any signed-in user may call them** (same line as sources).
- **Errors are dictionary keys**, with YouTube's message as untranslated `detail`.
- **Board shows score > 1 only** (top 20 fetched): sub-median videos are not outliers.
- A third client island, `ResearchAnalyzeButton`, beyond the form and toggle — it needs to show
  the action's result; no estimate on the label (the board does not read transcripts).
