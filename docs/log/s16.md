# S16 — Telegram capture

## Built

- `workers/telegram-capture/`: Wrangler Worker (own `package.json`, `tsconfig.json`, `wrangler.toml`),
  `src/handler.ts` (secret check in constant time via SHA-256 digests, silent allowlist, grammar via
  `src/lib/clips/telegram.ts`, ONE `insert … on conflict (url) do update set note = coalesce(…)`
  with `xmax = 0` for the Saved/Already-saved reply), `src/index.ts` (Neon HTTP), `scripts/setup.ts`
  (`setWebhook` with `secret_token`), README (BotFather, chat id, `wrangler secret put`).
- Worker unit tests (15, mocked Neon): parse, allowlist, secret, duplicate reply, files, errors.
- `saveClip` takes `brandId/purpose/tags/source` (insert only); `updateClipCapture` + `normalizeTags`.
- `POST /api/clips`: capture fields, hashtag grammar in the note, source `shortcut|share|web`.
- `/inbox`: brand, purpose and tag filters; chips per clip; inline edit (brand/purpose/tags).
- `/share`: brand, purpose, tags fields. `docs/CAPTURE.md`: Telegram section, new fields.
- `tests/integration/capture-ui.test.ts`: filters, re-save, inline edit, route, Worker SQL on real pg.

## Decisions

- Worker replies inside the webhook response (`method: sendMessage`): no bot token in the Worker.
- A file sent without a link gets `https://telegram.invalid/file/<file_unique_id>` (clips.url is the
  unique key and must be http(s)); platform `other`.
- Brand aliases: brand ids from `brands` (active, cached 5 min per isolate) plus optional
  `TELEGRAM_BRAND_ALIASES` JSON; an alias to an unknown brand is dropped.
- Inline edit is any signed-in user (free, reversible); retry/dismiss stay owner-only.
- New strings live in `dict/capture.ts` (the i18n snapshot pins `inbox.ts`'s keys).

## Known issues

- CI does not run `workers/telegram-capture` `npm test` (no workflow edits, §1.54); the handler is
  covered in CI through `capture-ui.test.ts` against Postgres. Run the Worker tests locally.
- A re-save (any door) updates only the note, so a later `#brand`/file on a known link is ignored;
  fix it with the inline edit.
- A shared caption's own hashtags (e.g. Instagram's `#travel`) become clip tags via the note grammar.
- Worker not deployed: needs Anton's Cloudflare account and bot token (README steps).
