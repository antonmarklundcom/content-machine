# O11 — Post engine

## Built

- `ai.ts`: `draftPost` (from an idea ungrounded, from a topic grounded, or a one-section rewrite),
  `adaptPost` (ungrounded rewrite for a sibling account), both through `structuredJson()` +
  `withSpendCap`; `transcribeClip` on Gemini Flash-Lite (always Gemini, media inline ≤ 14 MB or a
  file URI, refuses > 15 min for free); `generateContentPlan` takes an optional `topic`.
- `src/lib/posts/`: `assemble.ts` (model answer → `PostDraft`, repairs + UNSOURCED notes,
  `mergeSection`), `status.ts` (legal transitions), `guides.ts` (playbook/style guide loaders),
  `export.ts` (brief + pack builders), `engine.ts` (`createPostFromIdea`, `regenerateSection`,
  `adaptToFamily`, `setStatus`, `updatePost`, `exportBrief`, `exportPack`), `http.ts`.
- Routes: `POST /api/posts`, `PATCH /api/posts/[id]`, `POST /api/posts/[id]/adapt`,
  `POST /api/posts/[id]/regenerate`, `GET /api/posts/[id]/export?format=brief|pack[&as=json]`.
- `content/playbooks/{instagram,tiktok,facebook}.md`; `content/style/{es,pt-BR,de,nl,sv}.md`.
- Fake: `post` + `transcript` payloads/usage, `controls.payloadOverrides`; the video-URL fallback
  is now only an *analysis* request with a file URI.
- Tests: `tests/integration/post-engine.test.ts` (12), unit tests for assemble/status/guides/export.

## Decisions

- `generateContentPlan` gained an optional 5th `options` arg for the topic (the one change to an
  existing `ai.ts` call; needed for §5.O11.4). `ai-fake.test.ts` got the two new kinds (typecheck).
- Status moves: see `POST_TRANSITIONS`; `ready|scheduled → published` is the manual "mark posted".
- Adapt parents every sibling to the tree root and skips accounts already in the tree (re-runnable).
- `image_post` = one slide; brief visuals 4:5 feed, 9:16 vertical, FB image 1:1, YouTube video 16:9.
- Facts in the prompt: family facts in the account language (or its base), then brand facts;
  unverified ones are flagged "say only hedged". Lessons: hook/cta/caption_pattern.
- PATCH and export are signed-in only (free); create/adapt/regenerate are owner-only (spend).

## Known issues

- Fake still has no pack/shorts/prose payloads (b2b-c) — not cheap enough to fold in here.
- `transcribeClip` does not use the Files API: clips > 14 MB are refused (S17 can downscale).
- Scripts still map `sv` brands to English (`scripts/language.ts`, not O11's); posts use `sv.md`.
- `es.md` number format follows the market (no single LatAm convention).
