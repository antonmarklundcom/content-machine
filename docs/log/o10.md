## Decisions

- Missing drive: routes answer 503 `{code: "missing"}` (build 2's script route too, was 404);
  scripts exit 0 with the message. The scan skips `.`-names, `_thumbs/`, partial downloads.
- Manifest reader is tolerant: any array of `{file}` objects; `media/` prefix and
  manifest-relative paths resolve. S14's commands should write `brandId`/`accountId` at the top.
- Dedupe keeps the first path; a later register moves `local_path` only when the old file is gone,
  and fills blank metadata without overwriting.
- `publishCopy` sets `public_expires_at` = now + retention and re-extends on republish; prune
  keeps copies on `scheduled`/`publishing` posts. O13 may re-call `publishCopy` at post time.
- Server picks random names (`files/YYYY/MM/<32hex>.<ext>`); allowlist jpg/png/webp/gif/mp4/mov.
